# A1 全景图定义（Goethe-Zertifikat A1 · Start Deutsch 1）

全景图是产品的**进度度量层**：它不组织学习内容，只回答"完整的 A1 是什么、我还差什么"。
主线（今天学什么）按全景图的空白排序；用户也能点任意一格自己进去补。

权威依据：`tools/wortliste.json`（Goethe A1 官方词表，849 条）。
凡本文档与该词表冲突，以词表为准。词表里没有的结构，不进 A1 内容。

四条轴：**拼读 6 格 · 语法 20 格 · 词汇 14 主题 · 题型 11 格**。

## 〇、拼读轴（6 格）

放在全景图最上面一行。它不是语法，是地基——不会拼读，听力和口语都无从谈起。
按**回报率**排序（学完立刻能读出多少真词），不按字母表分类。

| 格 | 规则 | 学完立刻能读 |
|---|---|---|
| V1 | 五元音长短 + 三种长音标记（后跟单辅音 / h / 双写）+ schwa 弱化 | Name · Tag · fahren · Boot · bitte · kommen |
| V2 | **双元音 + 英语陷阱**：ei ai au eu äu ie ＋ w=v · v=f · z=ts · s+元音=z · j · qu ＋ 词尾清化 b d g | zwei · Wein · sieben · heißen · euch · und |
| V3 | **sch 家族 + ch**：sch · 词首 sp/st（词中不变）· ch 轻 [ç] / 重 [x] · -ig · tsch | Deutsch · Student · sprechen · ich · auch |
| V4 | **变元音 ä ö ü + r**（基础档 / 进阶档，见下） | Mädchen · schön · über · Bruder · Uhr |
| V5 | **收尾辅音 + 硬起首**：h · pf · ng/nk · tz/ts · -tion · x · y · -el/-en ＋ Knacklaut [ʔ] | Apfel · Zeitung · Platz · Achtung |
| V6 | 词重音 + 句子语调 + 拼写自己的名字（字母名只教用得到的） | 对接口语题型 P1 |

**每格的闭环（三段，缺一不可）**：

1. 一条规则（讲解 ≤ 100 字）+ 口腔动作描述
2. 5 个真词跟读 → Azure 评分 → 不达标进复习队列
3. 3 道**听辨题**（`ich` vs `isch`、`Bett` vs `Beet`、`schon` vs `schön`）

第 3 段是现有发音课完全没有的题型，也是让它从"参考资料"变成"课"的关键。
它同时训练发音和精听需要的耳朵分辨力。

### V4 的 r：两档，别拿它当及格线

**基础档（达标）**——覆盖德语里约一半的 r：
词尾 `-er`/`-r`、长元音后的 r 一律读成轻轻的"呃" [ɐ]：Mutter · Vater · aber · wir · mehr · Uhr。
达标标准只有一条：**Vater 不能读成"法特尔"**，舌尖不许动。

**进阶档（小舌音 [ʁ]）**——四条技巧，按有效性排：

1. **从"重 ch"借力（最管用）**：V3 学过的 `Buch` 里那个清嗓子音 [x]，发音位置和 [ʁ] 完全相同。
   发着 ach…ach… 然后让声带振动出声，[x] 就变成 [ʁ]。从已会的音过渡，比凭空找位置容易十倍。
2. **漱口定位**：含水仰头漱口，咕噜声的位置就是小舌。记住感觉，再不含水做。
3. **从"嘎"后移**：发汉语"嘎"时舌根抵软腭，把接触点再往后挪一点点。
4. **负面清单**：绝对不要卷舌——中国学习者头号错误。德语 r 舌尖全程贴下齿不动。

**必须给心理退路**：德国南部/奥地利用舌尖颤音，标准播音用小舌音，日常快语速里 r 常常几乎听不见。
r 读不标准**不影响别人听懂你**，是德语里容错度最高的音之一。所以它是挑战，不是门槛。

### 标音规则（硬约束）

> **可以用汉语描述嘴该怎么动，不可以用汉字表示德语该读什么音。**

- ❌ 删除：`tseh`、`ei 读"艾"`、`z 像"次"`、`eu 读"奥伊"` —— 汉字近似会把错音固化下来。
- ✅ 保留并大幅增加：`摆出说"衣"的口型，然后只送气不出声` —— 这是操作指令，说的是怎么做，不是读什么。

**IPA 保留**（德语标音就是 IPA，Duden 用的也是它），但摆正定位：**IPA 是标记，不是教学**。
教会发音的是音频 + 口腔动作 + 评分；IPA 的价值是精确、可查、和词典一致。
需要加一层交互：**点音标里的符号 → 弹出"这是什么音、在第几格学的"**，让它从装饰变成索引。

### 现有 `data/pronunciation.js` 的审计结论

**覆盖不是问题**——10 课把德语拼读规则讲到了 90% 以上，IPA 准确、例词恰当。
重排时素材基本可直接搬运。只漏三条，必须补进 V5：

| 漏掉的 | 为什么要紧 |
|---|---|
| **硬起首 Knacklaut [ʔ]** | 德语每个元音开头的词前有轻微喉塞：`Ich bin ein Arbeiter` 是四段不是连读。**这是中国学习者听起来"不像德语"的头号原因**——汉语习惯连音 |
| **tz / ts / ds → [ts]** | `Platz` `jetzt` `nichts` `abends` 全是 A1 高频词。讲了 z，没讲 tz |
| **词尾 -el** | `Onkel` `Löffel` `Schlüssel` |

（另：`-en` 只讲了"弱化成 [ə]"，未讲音节化 [n̩]——`sprechen` 是 shprech-n。A1 阶段可简化，但值得补一句。）

**问题全在结构**：

1. **10 课 0 道练习题**，唯一交互是"标记本课完成"。不会做错也不会做对，所以没理由认真读。
2. **按字母表分类**（"s 家族"、"w v z j qu"）——是语音学教科书的目录，不是学习顺序。
   且无难度梯度：sch/sp/st 很简单、ch 很难、小舌音 r 最难，三者平铺各占一课。
3. **第 1 课要背 30 个字母名**。字母名在 A1 只用于拼写自己的名字，零即时回报却放在最前面。
4. **用汉字标音**，见上面的硬约束。
5. **跟读评分是死路**：`phraseRow` 接了 Azure，打完分不重来、不进复习、不点亮任何进度。
   发音课至今没有 `skills` 标签，是唯一没接掌握度的模块。

### 明确不在 A1 的（内容生产的红线）

写内容时越过这条线，就是给学习者制造挫败感。审计工具应该拦住：

- **从句**——`weil` / `dass` / `wenn` 都不在考纲词表。A1 只有并列句。
- **形容词词尾变化**（ein guter Mann）——A1 只要表语用法（Der Mann ist gut）。
- **第二格** Genitiv，包括 trotz / wegen / während。
- **被动语态**。
- **Präteritum**，除 war / hatte 外一律不用。
- **Konjunktiv II**，除固定说法 möchte / könnte Sie… 外不用。
- **Wechselpräposition 的第四格用法**（Wohin? → in die Stadt）——A1 只要 Wo? 的第三格。

## 二、词汇轴（14 主题）

### 口径

- **分母**：考纲 849 条剔除符号(14)与纯数字(37) → 实词约 **694 条**（名 401 / 动 156 / 形 80 / 副 48 / 其他 9）。
- **分子**：`data/vocab.js` 里已教且命中考纲的词。当前 **约 310 条 ≈ 45%**。
- 功能词（冠词、人称代词、物主代词、介词、连词）**不计入词汇轴**，它们归语法格子。否则同一件事被数两遍。

### 现状

我们 438 个词里有 100 个不在考纲，但大部分不是超纲，是**格式差异**：
`guten Morgen` / `auf Wiedersehen` 这类整句短语、`eins, zwei, drei` 这种把数字打包成一条、
`Lehrerin`/`Ärztin` 阴性形（考纲收 Lehrer/Arzt）。真正的个性化超纲只有 `China`/`Chinesisch` 等少数几个，保留。

Person · Familie · Wohnen · Essen und Trinken · Einkaufen · Arbeit und Beruf ·
Freizeit · Reisen und Verkehr · Gesundheit · Schule und Lernen · Wetter ·
Dienstleistungen（邮局/银行/管理局）· Zeit und Termine · Kommunikation

## 四、零基础怎么进来（破冰期设计）

### 问题

主线的循环是"先听（不给文本）→ 再读 → 词 → 语法 → 复述"。
零基础的人第一天听不懂任何东西，会立刻走。而"办银行卡"这种真实任务，
对一个连字母都不会读的人**没有意义**——硬包装成场景就是假的。

### 结论：主线不是均质的，前面有一段破冰期

**破冰期 7 天，诚实地告诉用户"这一周我们打地基"，不假装它是生活场景。**
它的成功标准不是覆盖了多少格，是**第 7 天他还在**。

破冰期只做三件事，每件都无法用场景材料承载：

1. **拼读规则**（拼读轴 V1–V6，一天一格）。德语见字读音，比英语规则得多。
   学会了就能读出任何生词——这是听力的地基，也是**唯一一个学完立刻有巨大回报**的知识点。
2. **最小生存句**（整句背，不拆语法）。**不单独占一天，作为每天的跟读素材搭车。**
   `Ich heiße… / Ich komme aus China. / Ich verstehe nicht. / Wie bitte? / Können Sie das wiederholen?`
   后三句是"听不懂的时候怎么办"——先给用户一条退路，再让他去听。
3. **耳朵校准**：第一天必须听懂**一整句**，不是半句，宁可极短；第 7 天听懂**一整段**。

排期：Day 1–6 = V1–V6（每天含一句生存句），Day 7 = 首次听懂一整段 + 全景图首次点亮 6 格。

破冰期结束时，全景图上应该点亮 A1（sein）和 C1（名词的性）的入门格，
用户第一次看到那张 20 格的图时，上面已经有两格是绿的。

### 四条支撑机制

**1. "听"的方式随水平自动滑动，不换材料**

同一份材料，四种听法。全景图覆盖率决定用哪一档：

| 档 | 听法 | 适用 |
|---|---|---|
| 0 | 文本 + 中文对照，边看边听 | 破冰期 |
| 1 | 只给德语文本，边看边听 | 覆盖 < 25% |
| 2 | 先盲听一遍 → 再看文本 | 覆盖 25–60% |
| 3 | 只听，文本按需展开 | 覆盖 > 60% |

这就是"贴合水平"落在同一份材料上——**不用换内容，换用法**。
现在的精听是固定五阶段，所有人一样，这是要改的。

**2. 已知词保底线 ≥ 92%**

选材料时卡这条线。指标已经有了（`tools/audit_a1_content.mjs` 的难度检查，
上一轮已从恒等式改成逐词真实判定）。

**破冰期词汇量太小，够不到 92%，所以破冰期必须用专门写的受控材料，不能用真实语料。**
这也正好说明为什么语料层要等词汇量起来——不是工程排期问题，是数学上不成立。

**3. 开屏一次性分流（30 秒，只问一次，不是选择题）**

- 完全没学过 → 直接进破冰期
- 会一点 / 有基础想查漏 → 先做**全景图定位测**：20 格每格 2 题，40 题约 10 分钟，
  直接点亮已会的格子，主线从第一个空白格开始

**没有定位测，有基础的用户会被迫从"我是"学起，第一天就流失。**

**4. 永远有"听不懂"出口**

每一句都能一键：慢速重放 / 显示文本 / 逐词拆解。
对零基础，**听不懂是常态不是异常**——它必须是一个有出口的状态，不是一次失败。
（多邻国答错扣心，这里不该这么设计。）

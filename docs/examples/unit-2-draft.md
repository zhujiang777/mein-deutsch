- **整体短语**：Was ist das? · Keine Panik! 别慌 · Kein Problem! 没问题

### 语法卡：kein · nicht（放在第 10 句之后）

先做：

1. Das ist ___ richtig! → **nicht**
2. ___ Panik, Lin. → **Keine**
3. Das ist ___ Fehler. → **kein**

规则：否定名词用 kein，词尾和 ein 一样（kein / keine / kein）；否定动词、形容词等其他成分用 nicht。

| | | 例 |
|---|---|---|
| kein + 名词 | 阳性 | kein Fehler |
| | 阴性 | keine Panik |
| | 中性 | kein Problem |
| nicht | 形容词前 | nicht richtig · nicht da |
| | 动词的否定放句末 | Ich verstehe das nicht. |

### 发音卡：pf

先闭紧双唇，松开时上牙马上碰下唇送气，两个音连成一个。Pfand · Apfel（苹果）· Kopf（头）

### 生活小贴士

- **Pfand**：德国的饮料瓶和易拉罐大多带押金，一次性塑料瓶和罐是 25 分。空瓶拿到超市的退瓶机，机器出一张小票，结账时抵钱。

### 第 2 天

- **带字幕听时的问题**：小票上多出来的 25 分是什么？→ 瓶子的押金（算错了 / 袋子钱）
- **盲听题**：① 可乐本身多少钱？2,25 €（2,50 € / 2,15 €）② Lin 一开始以为是什么？算错了（押金 / 打折）③ 瓶子退回去会怎样？钱退回来（换一瓶新的 / 没有用）
- **听写**：第 0、3、7、10 句　**跟读**：第 2、4、9、11 句
- **复述**：照常（说话的就是 Lin）
- **开口回应**：
  - 看到小票上一个不认识的词，问“这是什么？” → Was ist das?
  - Tom：„Ist das ein Fehler?“ —— 告诉他不是错误，是押金 → Nein, das ist kein Fehler. Das ist Pfand.
  - 店员：„Das macht zwei Euro fünfzig.“ —— 你没明白 → Ich verstehe das nicht.
- **隔天检查**：① “这不对。” → Das ist nicht richtig. ② “没问题！” → Kein Problem! ③ “我不明白。” → Ich verstehe das nicht.

### 课后小材料（读）：Herr Krause 贴在厨房的通知

> An alle in der WG:
> Die Küche ist kein Lager!
> Hier stehen zwanzig Flaschen. Zwanzig!
> Das ist nicht in Ordnung.

## 第 2 单元总表和小测（提纲）

**总表：冠词一张表**（三课各学了一行，正好拼齐，没有要补的新格子，所以不需要“先教再考”的小对话）

| | 阳性 | 阴性 | 中性 |
|---|---|---|---|
| 定冠词 | der | die | das |
| 不定冠词 | ein | eine | ein |
| 否定 | kein | keine | kein |

另附：数字 0–100 的拼法一览；nicht 的两种位置。

**总表练习（约 6 道）**：冠词三选一（混合三行）；kein 还是 nicht；听价格；拼句。

**小测听力（没见过的一段）**：Tom 把厨房的瓶子退了，拿回 5 欧，得意地拉 Lin 去咖啡馆“这次真的我请”。点完一共 8 欧。Tom 掏出 5 欧，看着 Lin。Lin：„Kein Problem. Hier sind drei Euro.“
- 题：① Tom 从退瓶机拿回多少钱？5 欧 ② 一共要付多少？8 欧 ③ Lin 补了多少？3 欧

**小测开口**：① 在面包店问面包多少钱 ② 点一杯水 ③ 回答 „Zusammen oder getrennt?“ ④ “这不是错误，这是押金。”

**现在能做到**：听懂 100 以内的价格；在面包店、咖啡馆说要什么并付钱；说“没有、不是”，问“这是什么”；看懂小票上的押金。

## 要你定的 5 件事

1. **第 6 课怎么点阳性的东西。** `ich möchte` 后面的阳性名词要变成 einen（einen Kaffee），这是第 9 课才讲的第四格。草稿里绕开了：Tom 点的是 eine Tasse Kaffee、ein Stück Kuchen。另一种做法是把 „einen Kaffee, bitte“ 当整体短语先教。我倾向草稿的做法，学的人不会被没讲过的词尾绊住；代价是暂时不能直接说“一杯咖啡”最常见的那种说法。
2. **要加第五个声音：店员。** 面包店和咖啡馆的店员建议共用一个女声，以后超市、药店也用她。
3. **钱包用哪个词。** 草稿用 der Geldbeutel（好拼、能顺带认出 Geld）；das Portemonnaie 在科隆一带更常听到，但很难拼。
4. **第 7 课整篇是 Lin 的独白**，没有对话对象，所以开口题有两道是“假设 Tom / 店员问你”。这样可以吗？
5. **小测结尾**用“Tom 退瓶子换钱请客、还是差 3 欧”，把三课串起来。人设上 Tom 一直在欠账，你觉得合适还是太过？

# 怎么写一篇课文课

先读 [产品宪法](product.md)。本文件只放写内容时的现行规则。不要按旧模板（微步课、场景循环、全景格子、技能标签）写课。

## 一篇课文

- 30–80 词，对话或短文，是在德国真会遇到的情境；标出"我的角色"
- 只引入 1 个新语法点、1 个发音点；语法点和先后顺序按文末进度表，不自行调换
- 新词：第 1 单元每课 5–8 个；第 2 单元起课文写到 60–80 词、每课 8–10 个；其余用前面课文已教过的词
- **词包**：进度表里标了词包的课，另带一组成套的词（约 8–12 个），课文里出现其中一两个，其余用配对、听音选词等轻快题带出
- **成套的东西整套给**（2026-11-10 作者要求）：数字、星期、人称变位这类成套知识，第一次出现的那一课就把整套给全，不在课文里零散冒出单个成员
- **语法放在整张表里看**：语法卡带完整的小表，本课学的那几格点亮（`on`），其余灰着；每个单元结束出一张“单元总表”，把本单元学到的收成整张表，并补齐课文里没出现的格子（第 1 单元补 wir / ihr / sie），和小测放在一起
- **有事发生**：用固定人物（见进度表），每篇有一件小事（误会、求助、小尴尬、小笑点），有头有尾；口语像真人说的，短句，常用口头语按整体短语教
- **真问题**：理解题必须要听懂/读懂才能答，不出“对话里有几个人”这类假问题
- **一人一声**：每句标明说话人，音频按“角色 + 句子”生成
- 需要但还没系统讲的表达，标注"按整体短语学"
- 所有名词带冠词；动词连同常用搭配/支配格一起给
- 讲解用中文、原创，每张卡不超过两句；不用中文谐音或绝对化的发音口诀

## 两天的步骤都从课文来

- **预习**：听之前先认 4–6 个“听懂大意必需”的词或短语（从本课新词里挑，配图标和读音），并认一下出场人物
- **带着问题听**：听全文时只给一个具体问题（例：Tom 请 Lin 喝什么？），答案必须落在预习过的词上；听到预习词的那一句，把这个词亮出来
- 听、精读、听写、跟读、复述用的都是这篇课文本身的句子
- 听写必须逐句打字，不用选词块
- 复习卡的例句用课文原句
- 配套泛读/泛听小材料以本课和前面已教的词为主，另带 3–5 个新词（必须有点词释义）

## 界面上的字

- 只写“要做什么”，一屏最多一句任务；能用版式和图标表达的就不写字
- 不写教学法说明（“先不看文字……”）、不写安慰（“听不懂没关系”）、不写给评审看的话（“这是样板”“只有一个语法点”）
- 答题反馈只给结果和正确的德语，不加点评

## 教材与版权

- 教材（Nicos Weg、Menschen 等）只作语法顺序与题材参考
- 正文、讲解、题目全部原创；教材原文、页面、音频不进仓库（只能留在本地 `正版图书/`）

## 德语质量红线

- 变位、变格、词性、复数逐个核对；语序符合动词第二位与句框规则
- 题目答案唯一；填空写全所有可接受写法
- 不为了指标好看而虚标"该词出现在本课"；登记的词必须真的出现在课文里

## 改完内容后

1. `npm run content:index` → `npm run content:examples` → `npm run content:grammar`
2. 改了德语文本：`python3 tools/gen_audio.py`；生成后人工抽听
3. `npm test` 必须全绿

## 数据放在哪

新版故事课（第 0 课起，按进度表写的）放在 `data/story-lessons.js`，字段见 `docs/schema.md` §6，暂未接入应用；配音清单用 `node tools/voice-script.mjs` 生成。下面是正式版仍在用的旧结构：

课文课写在 `data/text-lessons.js`，以第 1 课 `tl-01` 为样板，一课一个对象：

- `lines`：课文逐句（说话人、德语、中文），`role` 是“我的角色”
- `gloss`：点词释义，课文和课后小材料里的每个词都要有
- `words`：进入复习的词（词库 id + 所在句 + 句中词形），复习时用这句出填空
- `cards`：语法卡、发音卡各 1 张，生活小贴士可选，`after` 是插在第几句之后
- `gist`（盲听大意题）、`checks`（第 1 天小检查）、`dictation`（听写哪几句）、`shadow`（跟读哪几句，只能是我的角色）
- `reviews`：3 道隔天检查变式；`reading`：课后小材料 + 1 道理解题
- 选择题把正确项写在第一个，页面会自动打乱顺序
- 改了已上线的课文内容就把 `version` 加 1（学习记录按版本分开）

`tests/text-lesson.test.mjs` 会检查：词数 30–80、下标有效、词在词库、释义齐全、小材料不超纲（“小材料可带 3–5 个新词”的检查，在新版铺进正式版时一起更新）。

- 第 1 单元每课 1 天，其余每课 2 天；全程约两个月。每 4 课一次小测。
- 每课的发音点写课时再定，顺序参考《当代大学德语》语音部分与《走遍德国》各课 Aussprache。
- 顺带放进课文、不单独成课：其他物主词（sein / ihr / unser，第 9–10 课起）；“去哪儿”（in die Stadt、nach Hause、zum Arzt，第 16–17、24 课）；时间介词（am Montag、im Mai、von … bis，第 11、25 课）。
- 词包分配：3 数字 0–12 · 5 数字 13–100 · 6 饮料与点心 · 8 冰箱里的食物 · 9 家人称呼 · 10 颜色与常用形容词 · 11 星期与一天的时段 · 12 日常动作 · 14 爱好 · 16 交通工具 · 17 城市里的地点 · 18 房间与家具 · 20 蔬果与包装量词 · 23 身体部位 · 25 月份与日期 · 28 常用动词的过去分词 · 29 季节与天气。
- 词汇目标约 550–600 词（歌德 A1 词表八九成）；每写完一批课做一次覆盖检查，词表只在本机对照，不进仓库。
- 2026-11-10 调整（作者同意）：数字 0–12 从第 5 课提前到第 3 课整套教；每个单元末加单元总表。
- 不放进这 30 课（超出 A1）：比较级最高级、dass / weil 从句、情态动词过去时。留到阶段转向之后。

# 怎么写一篇课文课

先读 [产品宪法](product.md)。本文件只放写内容时的现行规则。课文课的数据格式在"第 1 段"实现时补到本文件和 `schema.md`；在那之前不要按旧模板（微步课、场景循环、全景格子、技能标签）批量写课。

## 一篇课文

- 30–80 词，对话或短文，是在德国真会遇到的情境；标出"我的角色"
- 只引入 1 个新语法点、1 个发音点；新词每课 5–8 个，其余用前面课文已教过的词
- 需要但还没系统讲的表达，标注"按整体短语学"
- 所有名词带冠词；动词连同常用搭配/支配格一起给
- 讲解用中文、原创、简短；不用中文谐音或绝对化的发音口诀

## 两天的步骤都从课文来

- 盲听、精读、听写、跟读、复述用的都是这篇课文本身的句子
- 听写必须逐句打字，不用选词块
- 复习卡的例句用课文原句
- 配套泛读/泛听小题要复用本课和前面课文已教的词

## 教材与版权

- 教材（Nicos Weg、Menschen 等）只作语法顺序与题材参考
- 正文、讲解、题目全部原创；教材原文、页面、音频不进仓库（只能留在本地 `正版图书/`）

## 德语质量红线

- 变位、变格、词性、复数逐个核对；语序符合动词第二位与句框规则
- 题目答案唯一；填空写全所有可接受写法
- 不为了指标好看而虚标"该词出现在本课"；登记的词必须真的出现在课文里

## 改完内容后

1. `npm run content:index` → `npm run content:examples` → `npm run content:grammar`
2. 改了德语文本：`python3 tools/gen_audio.py`；生成后人工抽听
3. `npm test` 必须全绿

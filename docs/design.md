# 界面和插画怎么做

先读 [产品宪法](product.md)。界面照作者自己的设计系统「德语手帐本」做（私有页面，地址问作者；本机的开发记忆里有）。设计系统和宪法冲突时以宪法为准。

## 这套界面认什么

作者否掉过两轮“通用模板风”的界面。现在这套是从项目自己长出来的：一本手帐、合租公寓的厨房、贴纸、荧光笔、手绘线。新画面先问一句：它像不像这本手帐里的一页？

- **一屏只做一件事**，底部一个大按钮，顶部一条整课的进度尺。
- **界面上只写“要做什么”**。不写教学法说明、安慰的话、给评审看的话。
- **词性颜色贯穿全应用**：阳性 der 蓝、阴性 die 红、中性 das 绿；不分性的词用黄色荧光笔。名词出现的地方（词卡、词表、语法表、封面标签）都跟着这套颜色。
- **成套的东西分屏给**：一屏一组，每组讲一句规律。不要一屏堆二十个词。
- **看知识的页面要宽松**：手帐里点开一条，纸放宽到整屏、签收起来。
- **人物**：每个角色一张固定头像、一种固定颜色（进度条、头像底色）。

## 文件分两类

| 文件 | 谁的 | 规矩 |
|---|---|---|
| `heft/css/tokens.css`、`heft/css/ds.css`、`heft/js/sprites.js` | 设计系统的原样拷贝 | 不手改里面已有的东西。设计系统更新了就重新拷。`sprites.js` 里只追加过新角色头像（`verk`） |
| `heft/css/heft.css`、`heft/js/art-lessons.js`、`heft/js/sprites-extra.js`、`heft/js/mouth-sprites.js` | 应用自己的 | 新样式、每课的画、补充图标、口型图都放这里 |

颜色、字号、圆角只用 `tokens.css` 里的变量，不新造颜色。

## 新画面怎么来

1. 先做原型，不直接改应用。原型放 `lab/ds-explore/roundN/`（不进仓库），每一轮在 `lab/ds-explore/notes.md` 记一段：做了什么、作者怎么说。
2. 拿不准方向时给两三个方向让作者挑，并说自己倾向哪个。
3. 作者点头后做进 `heft/`，按手机宽度（约 412 宽，再看一次 620 高的矮屏）在本机看过，再问要不要上线。
4. **作者说某处难看，只改被点名的那一处**，其余不动。觉得要换整体方向，先用一句话问他。
5. 动效手感在预览里看不出来（预览会把动画冻住），只能核对前后状态；如实告诉作者“动作要你在手机上看”。

## 每课要画的三样

规格都写在 `heft/js/art-lessons.js` 开头的注释里，现成的画就是样板。

**预习贴纸**（每课 5–6 张，对应预习词）
- `PICS[name]`，viewBox `0 0 96 96`，用 `pic(...)` 包起来（自带白色贴纸边），图形四周留 10 以上。
- 画法：手绘墨线（`ink`）+ 往右下错开一点的色块（`off`）+ 网点（`dots`）。
- 名字用小写德语词，不带变音字母（`geldbeutel`、`zurueck`）。数据里 `preview[].pic` 写同一个名字；没有这张画时页面自动用无图版式，不会坏。
- 抽象的词也要想个具体的东西来画：“多少钱”画价签，“一共”画小票，“分开付”画撕成两半的小票，“错误”画被红笔圈出来的一行。

**首页封面场景**（每课 1 张）
- `SCENES['sl-NN'] = { svg, labels }`，viewBox `0 0 300 220`，引线画在图里。
- `labels` 是 2–3 个本课名词，带冠词（上词性颜色），`x / y` 是这个词左上角在场景里的相对位置。场景宽约 232px、字 15px 时不压到物品。
- 画这一课最有代表性的两三样东西，不画人。

**新角色头像**（很少）
- `<symbol id="..." viewBox="0 0 48 48">`，和现有五个放在一起看要像一家人；30px 的小尺寸下也认得出。
- 加角色要先问作者；同时要在 `art.js` 的 `PERSON`、`NAME`，`screens.js` 的 `TL_COLOR`，数据的 `STORY_CAST` 四处登记。

**图里的字**一律用 `txt(...)`。`FONT` 那一行只能用单引号（它要插进 `style="…"`，用双引号会让所有字号失效，2026-11-16 修过一次）。

## 画完怎么进应用

1. 新画先放 `lab/ds-explore/roundN/`：`pics.js`、`scene.js`、一个能和现有的画并排看的 `preview.html`。
2. 能复用的常量直接用，不重复定义。
3. 贴进 `art-lessons.js`：场景代码放 `export const SCENES` 前面并在里面加条目；贴纸放 `export const PICS` 前面并把名字加进那一行。
4. `node -e "import('./heft/js/art-lessons.js')"` 能通过，本机看首页封面和一张预习词。
5. 发布前再核对一次：进了应用的是不是最后一版。

## 口型图

`heft/js/mouth-sprites.js`，现有：`m-ae`、`m-oe`、`m-ue`、`m-ich`、`m-ach`、`m-sch`、`m-wv`、`m-z`、`m-r`。发音卡用 `pics: ['m-…']` 引用；没有合适的图就不配图，不要硬凑。改口型图同样只改被点名的那一张。

# 待办清单：从现在到上架之后

没方向的时候看这里。方向本身以 [产品宪法](product.md) 为准；这份清单只管“接下来做什么”。

- 做完一项就把 `[ ]` 改成 `[x]`，并在后面写上日期。
- 每次收工，接手开发的模型更新最上面“现在该做的三件事”。
- 时间都是估计（按你每天 15–20 分钟、一个单元两周左右算），不是承诺。顺序比日期重要。
- 标【你】的只有你能做；标【一起】的是模型做、你来审或拍板；没标的模型可以直接推进。

## 现在该做的三件事（2026-11-16 更新）

1. 【你】在手机上把第 5–7 课和第 2 单元小测学一遍，哪里不顺就截图说。
2. 【你】听一听新录音（店员、Tom、Herr Krause 的新句子），有读错读怪的告诉模型重录。
3. 【一起】开第 3 单元：对模型说“按 docs/course-outline.md 起草第 3 单元，草稿先给我审”。

## 阶段 1 · 内容到 10 课（11 月下旬 – 12 月上旬）

目标：第 3 单元上线。到这里就有 10 课 + 3 次小测，够一个新用户学三周。

每个单元都是同一套循环（以后每个单元照抄这七项）：

- [ ] 【你】扫一眼大纲里这个单元，有想改的先说
- [ ] 模型起草三课 + 总表小测提纲 → 【你】审草稿、定“要你定的事”
- [ ] 模型做进应用、请设计线画贴纸和封面、录音、测试、本机看
- [ ] 【你】点头上线
- [ ] 【你】在手机上学一遍，反馈；模型只改你点名的地方
- [ ] 对一次歌德 A1 词表覆盖，把缺的词记到后面的课里
- [ ] 回头把大纲改到和成稿一致

第 3 单元特有的：

- [ ] 【你】定：Lena 的妹妹 Mia 要不要出场、加不加新声音（大纲默认只在照片里）
- [ ] 单元末加辨音题（宪法里欠着的）
- [ ] 第 3、4 单元写完后回头看：一课的结构有没有再改过（第一道闸）

## 阶段 2 · 让外人试用（12 月）

目标：5–10 个人学完第 1 单元，知道他们卡在哪、第二天回不回来（第五道闸）。不追求人数。

试用前先补四样（都是小功能，但没有它们试用会白做）：

- [ ] 第一次打开的引导：这是什么、每天做什么、大概多久（一两屏，不啰嗦）
- [ ] 进度备份：能导出、能导入，或者一个“换手机继续学”的口令
- [ ] 反馈入口：「我的」里一个按钮，能发一句话和当前在哪一屏
- [ ] 隐私说明：录音会发到评分服务；进度只存在本机

找人和观察：

- [ ] 【你】找 5–10 个人：身边的交换生、准备来德国的同学。一对一发链接
- [ ] 【你】每人学完第 1 课后问三句：哪里卡住了、哪里觉得多余、明天还想不想学
- [ ] 把意见汇总成一张表，按“卡住的人数”排序，只改前三条
- [ ] 改完再找两三个新人验证一遍

同时做“有没有人想要”的测试（不需要产品做完）：

- [ ] 【你】发一两篇过程帖（交换生自己做德语 App），留一个候补名单的入口
- [ ] 看有多少人留名、他们问得最多的是什么——这决定后面先做什么

## 阶段 3 · 内容继续 + 定几件大事（1 – 2 月）

内容：

- [ ] 第 4 单元 日常作息（第 11–13 课）
- [ ] 第 5 单元 兴趣与邀约（第 14–15 课）
- [ ] 第 6 单元 城市出行（第 16–17 课）

到这里约 17 课，A1 过半。做 App 之前必须由你拍板的几件事，每件定了都写进宪法：

- [ ] 【你】主要用户在哪：国内还是海外。这决定后台用谁家的、要不要备案、上哪些商店
- [ ] 【你】怎么收费：哪些课免费、之后是订阅还是买断、大概什么价位
- [ ] 【你】名字定不定：“Mein Deutsch” 很通用，上架前查一下商店里有没有重名、能不能注册
- [ ] 【你】用谁的名义上架：个人还是公司（影响开发者账号、收款、报税）
- [ ] 配音的商用授权：核对当前套餐允许不允许放进收费 App
- [ ] 内容自查：课文、题目、录音都是原创；教材只留在本机
- [ ] 算一笔账：一课的成本（录音额度 + 时间）、评分每用一次多少钱、定价能不能盖住

## 阶段 4 · 做成 App（2 – 4 月，五道闸都过了再开工）

开工前确认五道闸：结构稳定、≥10 课、成本算得清、评分可用、有外人学完第 1 单元。

底座（先做，iOS 和安卓共用一套）：

- [ ] 现有界面包成 App，真机上能完整学一课
- [ ] 账号：注册、登录、注销
- [ ] 进度同步：换手机不丢；旧的本机进度能迁进账号
- [ ] 课程和录音放到云端，按课下载；更新课程不用重新上架
- [ ] 没网也能学已经下载的课
- [ ] 学习提醒（每天一次，能关；不做断签惩罚）
- [ ] 发音评分按账号限次数；评分挂了不卡课

体验（真机上才能做的）：

- [ ] 动效手感一次调完：首页进入、封面翻开、翻页、拖拽、盖章
- [ ] 矮屏、大字号、深色模式下不破版
- [ ] 麦克风、通知的授权提示写清楚为什么要

钱和合规：

- [ ] 应用内付费接好，免费课和付费课的线划清
- [ ] 隐私政策、用户协议（录音、账号、付费）
- [ ] 账号注销和数据删除的入口（商店审核会查）
- [ ] 【你】如果面向国内：备案、软著、国内安卓商店各自的要求，提前一两个月开始办

看得见的数据（上线前就要有，不然上线后是瞎的）：

- [ ] 第二天回来的比例、学完第 1 单元的比例、每一屏的退出人数
- [ ] 崩溃和报错能看到
- [ ] 反馈入口接到一个你每天会看的地方

## 阶段 5 · 上架（4 – 5 月）

先 iOS，后安卓。

iOS：

- [ ] 【你】注册苹果开发者账号（年费）
- [ ] 商店素材：图标、截图、一句话介绍、长介绍、关键词、隐私标签
- [ ] 内测：先发给试用过的那批人，收一轮问题
- [ ] 提交审核；被打回就按意见改
- [ ] 【你】定上线日期，上线

安卓：

- [ ] 【你】注册谷歌开发者账号（一次性费用）；新的个人账号上架前要先做一段封闭测试，人数和天数以当时的要求为准，提前找好人
- [ ] 同一套素材改成安卓的尺寸
- [ ] 提交、上线
- [ ] 如果面向国内：再逐个上国内商店

上线当天：

- [ ] 给候补名单发通知
- [ ] 【你】发一篇上线帖
- [ ] 盯三天：崩溃、付费能不能走通、评分服务顶不顶得住

## 阶段 6 · 上线之后（持续）

每周：

- [ ] 【你】看一遍反馈和商店评论，回复差评
- [ ] 看三个数：第二天回来的比例、学完第 1 单元的比例、最多人退出的那一屏
- [ ] 挑一个最痛的问题，下个版本修掉

每两周一个小版本：修问题 + 上新课。大改动不超过一个。

内容：

- [ ] 第 7 单元 住所（第 18–19 课）
- [ ] 第 8 单元 饮食与购物（第 20–22 课）
- [ ] 第 9 单元 身体与求助（第 23–24 课）
- [ ] 第 10 单元 预约与留言（第 25–26 课）
- [ ] 第 11 单元 近期经历（第 27–29 课）
- [ ] 第 12 单元 + 结业小测（第 30 课）——到这里约等于 A1

学完 A1 之后（宪法里“阶段转向”和“以后”那几条，到时候由你决定）：

- [ ] 转向精读 + 泛读 + 泛听怎么过渡
- [ ] 课外扩展词库（可选加练，不成为第二条主线）
- [ ] 随手记一句（生活里听到的句子变成复习卡）
- [ ] 要不要做 A2

## 一直有效的提醒

- 改“一课怎么上”、换主线、加第二条学习线：都要你拍板并改宪法，模型不能自己做。
- 用户反馈里常会有人要排行榜、连续打卡、红心——宪法写了不做，除非你改主意。
- 一次只推进一个阶段的重点；内容可以和任何阶段并行，别的不要并行太多。
- 卡住超过一周的事，写在这里，下次开工先看它。

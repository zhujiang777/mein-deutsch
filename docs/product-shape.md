# 产品形态：综合课程试点（2026-09-06）

本文件替代“每日文章为核心”“先完成发音六关”的旧约定。未更新的旧设计文档仅作历史参考。

帮助初学者逐步完成日常交流，兼顾 A1。核心教学预先编写、核验和配音，AI 只作用户主动开启的可选加练。

| 入口 | 职责 |
|---|---|
| 学习 | 按生活能力编排的综合课、最多三个课前复习、单元检查 |
| 单词 | 当前课程词表、到期复习、已学词、生词本、其他词表 |
| 读听 | 短而容易的分级材料；默认自由读听，点击练习后才答题 |
| 我的 | 学习记录、语法和旧资料、设置、导出导入与同步 |

首页突出当前单元、继续课程和预计时长。规则表、译文、AI 按需展开。使用系统字体、纯色与一种强调色；练习中不弹 XP 奖励。必要的录音状态、错误提示和返回入口必须保留。

## 课程与学习记录

全程六阶段、十二单元，顺序显式登记在 `data/integrated-course.js`。首轮只有两个单元、八课和四份配套短材料。之后十个单元登记框架，不标记已交付，也不自动接入旧课。详细依赖见 [综合课程框架](integrated-curriculum.md)。

每课以同一生活任务为中心，理解材料、必要讲解、有提示练习、独立回答和表达相互配合；不追求题型齐全。每个活动注明训练对象。新词先看意思再练，旧词先抽查。

“已学习”“独立检查通过”“延迟复习通过”分别记录。跳过表达留为待练，完成即可进入下一课；口语自评与机器评分分开，机器评分不负责解锁。旧完成记录不转换为新课程掌握。

主动回忆与分散练习是设计基础。研究支持这两类方法的广泛用途，但不直接证明本产品的效果，也不指定统一间隔。[Dunlosky 等，2013](https://www.psychologicalscience.org/publications/journals/pspi/learning-techniques.html)

10–15 分钟、每日新增五词、约第 1/3/7 天复习均为待试学调整的参数。答错次日再练，单次最多一次有帮助的重试；自主加练不提前冒充延迟检查。用户可以休息、退出并恢复。

## 单词与读听

课程与单词模块共用现有词条、SRS 和每日额度，新用户默认五个新词；老用户保留设置。课程超出额度的练习证据保留为待加入，后续单词练习优先处理。仅查词不产生掌握记录。文字辨认、听音辨认、主动回忆分别记录；同一轮的三个角度不重复推进复习日程。

单词表并不等于已学词表。AI 校验把 A1 允许词与实际练过的词分开，覆盖率按正文词次统计；试点另限制已教表达范围。该校验是保守过滤器，不能代替语言教师审读。失败回固定练习，不阻挡课程。

读听不分成四条任务线。课程原文可重练，另外四份短材料帮助检查换人名、地点和数量后的理解。初学者无需攒够词汇才可进入。

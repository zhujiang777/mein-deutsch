# A1 精听 / 精读教材驱动生产计划

本文件是 A1 内容生产的正式依据。`docs/archive/listening-slice-plan.md` 只保留播放器、课程外壳、音频和 iOS 等技术基线；如两者冲突，以本文件的内容边界和生产门禁为准。

## 1. 生产目标与门禁

- 最终 24 个精听包、24 篇精读，L1–L6 / R1–R6 每阶段各 4 份。
- 第一批只交付 6 个精听、6 篇精读。12 份全部通过自动审计和人工验收后，才补每阶段其余 3 份。
- 主课决定语法上限，课程词汇与用户 SRS 决定推荐标签；精听、精读不与生存场景一一对应。
- 所有内容始终可打开。标签只表示“正合适 / 稍难 / 挑战 / 适合复习”。

## 2. 证据链

每份材料的 `designReferences.evidenceIds` 至少覆盖三类证据：

1. 仓库课程进度，并由《走遍德国》或《当代大学德语》辅助校准；
2. 对应 Hueber 技能书的页码、练习与音轨（阅读无音轨）；
3. Goethe、VHS、Nicos Weg 或 Deutsch im Blick 的公开校准。

可定位的来源、页码、练习、音轨和抽象观察统一维护在 `data/syllabus-ref.json`。商业教材全部标为 `abstract-only`；公开材料本批也仅作校准。正文不得复用任何教材人物、情节、题干、选项或信息顺序。

## 3. 试点规格

| 阶段 | 原创内容 | 核心任务 |
|---|---|---|
| L1 | 多说话人身份信息 | 匹配人物、来源和学习目的 |
| L2 | 姓名拼写、电话和课程编号 | 辨别字母及相近数字 |
| L3 | 公共通知的时间/地点变化 | 分清旧信息与新信息 |
| L4 | 休闲计划短采访 | 区分建议、意愿与最终决定 |
| L5 | 连续路线说明 | 还原地标顺序和空间关系 |
| L6 | 周末经历微叙事 | 重建完成时事件顺序 |
| R1 | 人物登记表与简介 | 扫描字段并重组信息 |
| R2 | 商品标签与迷你目录 | 理解冠词、复数、价格和用途 |
| R3 | 日程表附短消息 | 连接时间、活动和变更原因 |
| R4 | 休闲活动节目单 | 按多个条件比较选项 |
| R5 | 两则住房信息 | 比较地点、设施和方位 |
| R6 | 同一次旅行的两种复述 | 比较事实、评价和顺序 |

## 4. 固定生产流程

1. 在 `data/syllabus-ref.json` 冻结阶段规格和证据 ID。
2. 作者只看抽象规格，在空白页设计新人物、信息和表达。
3. 静态检查推荐课次、必要语法、基线词汇覆盖率及 3–6 个新 lemma。
4. 对本地 OCR、公开校准材料、现有课程和场景文本执行连续词重合审计。
5. 人工复核自然度、信息密度、声音依赖、篇章理解与重复感。
6. 正文冻结后才生成原创 TTS；出版商音频不得替代。
7. 12 份试点人工批准后，才启动第二批 36 份。

## 5. 学习闭环

- 精听固定为盲听 → 大意 → 听写 → 对照 → 跟读/复述。
- 精听听写或复述首答错误写入 `l:<packId>:<sentenceIndex>`，在每日路线中复现原音频和原句。
- 阅读固定包含预测、定位、篇章关系、理解题和概括。
- 阅读理解错误只更新阅读技能与尝试状态；不得把整句写入词汇 SRS。
- 打开材料不等于学会新词。只有查词或主动加入生词本才进入词汇 SRS。

## 6. 自动与人工验收

- `recommendedAfter` 必须指向真实课程。语法边界区分**看懂**和**会用**：没学过 `kann + Infinitiv` 也能看懂 `Man kann die Lampe aufladen`，超前的输入是正常语言接触，不拦。`tools/audit_a1_content.mjs` 的 `grammarChecks` 只在两种情况下卡门禁——
  1. 超前结构出现在**要求听写或复述**的句子里（那句学习者得自己生成出来，语法是硬要求；跟读是照着念，不算）；
  2. 超前句超过全篇 1/3——那不是偶尔遇到，是难度定错了。

  其余一律进 `report.grammar.receptiveNotes`，供人工判断但不拦。检测覆盖：情态动词（<L4/R4）、第二分词与 war/hatte（<L6/R6）、Präteritum（war/hatte 除外）、二格介词。
- 已知词率不低于 92%。分母是全部 token，分子只认词库（Goethe A1 + 课程词表）与已声明专名；`newLemmas` 按定义算未知，仅在同一生词重复出现时免罚后续几次（复现是设计，不是额外负担）。`targetLemmas` 不能把词库外的词声明成已知——那样指标会退化成文本长度的函数。
- 每份只引入 3–6 个新 lemma。词库缺的 A1 基础词补进 `tools/gen_dict.mjs` 的 `A1_GAPS`（同时修好查词弹窗），不得在审计工具里维护放行名单。
- 每个 `evidenceId` 必须存在，且每份内容覆盖上述三类证据。
- 六词连续重合直接失败；五词重合必须进入人工白名单并说明固定表达理由。
- 精听答案必须依赖声音，盲听阶段不显示正文；精读不得退化为逐句翻译。
- 12 份人工检查均完成前，`docs/archive/a1-pilot-review.md` 保持未批准状态。
- 第二阶段每完成一个阶段的 8 份内容，单独人工抽查；难度漂移只返修该阶段。

## 7. 延后项

Tatoeba、Wikinews 和 Common Voice 不进入当前试点。它们只在教材驱动的 12 份内容验收后重新评估。

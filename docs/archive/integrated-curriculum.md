## 两个试点的实际内容

每课均有核心材料、简短讲解、词汇练习、变式回答、可选录音对照和三份延迟变式。每单元第四课含未见过的听力信息与多句回应。核心词条复用既有词库（其中数字条目是词组，不能把卡片数当作独立词形数量）。需要但没讲透的格变化作为整体表达注明。

| 课程 | 重点任务 | 独立运用 |
|---|---|---|
| ic-01 问候与名字 | Ich heiße；Wie heißt du | 替 Tom 自我介绍 |
| ic-02 来自哪里 | Ich komme aus；Woher | 更换国家回答 |
| ic-03 住在哪里 | Ich wohne in；Wo | 更换城市回答 |
| ic-04 交换个人信息 | 姓名、来源、住处合用 | 新人物听力、三句自我介绍、询问姓名 |
| ic-05 数量与常见商品 | 数量、小面包、0–6 | 更换数量提出需求 |
| ic-06 提出购买需求 | möchte；咖啡/茶；7–10 | 更换商品购买 |
| ic-07 听懂简单价格 | 询价；整数金额；11–20 | 新金额听辨、自己询价 |
| ic-08 完成一次购买 | 需求、价格、请求重复 | 新购买听力、完整需求、请求重复 |

每单元两份读听材料：一位新同学、在 Berlin 见面；一杯茶、确认价格。自由读听不强制练习；练习成绩也不自动提升课程掌握。

## 试点需要观察的设计问题

- 4–5 张重点卡中数字词组负担可能偏大，要看实际用时和隔天回忆决定是否拆分。
- 固定答案检查接受标点、大小写和已写入的同义回答，但不保证识别所有正确表达。个人信息口语以自评记录，避免强迫人人照抄范文。
- 读听材料可提前打开；首次打开不自动视为掌握，先看过的“新材料”不能再被当作完全陌生的迁移证据。
- 未来单位的知识细化必须先检查先修与复现，再生产内容，不按语法目录批量堆课。
